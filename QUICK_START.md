## Deploy to Vercel in 5 Minutes

1. **Create GitHub repo:** https://github.com/new
2. **Push code:**
   ```bash
   cd /Users/skrishnamurthy26/Documents/website/propel
   git config --global user.name "Your Name"
   git config --global user.email "your@email.com"
   git remote add origin https://github.com/YOUR_USERNAME/propel.git
   git push -u origin main
   ```
3. **Deploy:** https://vercel.com/new → Select repo → Deploy
4. **Set environment variable:** `NEXT_PUBLIC_API_URL=http://localhost:5000`
5. **Live!** ✅
