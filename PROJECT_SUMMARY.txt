================================================================================
                          API ENDPOINTS (15 total)
================================================================================

Authentication (2)
   POST   /auth/register           Create new account
   POST   /auth/login              Login user

College Calculator (1)
   POST   /college/calculate       Calculate matches

AP Exam Prep (4)
   GET    /ap-prep/frqs            List FRQs
   GET    /ap-prep/frqs/:id        Get FRQ detail
   POST   /ap-prep/attempts        Submit response
   GET    /ap-prep/progress        Get user progress

Physics Simulator (3)
   GET    /physics/simulations     List simulations
   GET    /physics/simulations/:id Get sim config
   POST   /physics/states          Save state
   GET    /physics/states          Get saved states

Study Tool (5)
   GET    /study/decks             List decks
   GET    /study/decks/:id/cards   Get deck cards
   POST   /study/session           Start session
   POST   /study/card-result       Submit result
   GET    /study/progress          Get progress
